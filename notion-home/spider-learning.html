FULL KNOWLEDGE MAP

完整知识地图 · 八大模块

黄色卡片 = 当前正在学
01

机械与机构

解决“它为什么站得住、舵机够不够力”。

  • 自由度 DOF / 转动副 / 连杆
  • 力矩 / 重心 / 支撑多边形
  • 结构刚度 / 装配干涉
  • CAD / 3D 打印公差
验收：能看懂并修改一条腿的结构
02

电子与供电

解决“为什么一动就掉电、重启、发疯”。

  • 电压 / 电流 / 功率 / 共地
  • 堵转电流 / BEC / 降压
  • 电池与供电余量
  • I²C / UART / PCA9685
验收：能自己画可靠接线图
03

嵌入式控制

解决“代码怎么进入真实机械世界”。

  • ESP32 / C/C++
  • 变量 / 函数 / 循环
  • 状态机 / 定时 / 非阻塞
  • I²C / Wi-Fi
验收：能独立写基础控制程序
04

舵机与执行器

解决“怎么稳定、柔和地控制关节”。

  • 角度 / PWM / 脉宽
  • 机械零位 / 软限位
  • 死区 / 回差
  • 速度限制 / 插值 / 平滑轨迹
验收：1 个舵机真正听话
05

机器人运动学

解决“控制脚的位置，而不是猜舵机角度”。

  • 三角函数 / 向量 / 坐标系
  • 连杆几何
  • 正运动学 FK
  • 逆运动学 IK
验收：输入脚尖坐标 → 自动算关节角
06

多足步态

解决“多条腿怎么一起走还不摔”。

  • 支撑相 / 摆动相
  • 步态周期 / 相位差
  • duty factor
  • 脚尖轨迹 / 静态稳定
验收：多腿能稳定站住并行走
07

机器人软件架构

解决“上层只说 wiggle，底层自己干活”。

  • 关节层 → 脚尖层 → 动作层
  • 动作队列 / 优先级
  • watchdog / stop
  • HTTP / WebSocket / JSON
验收：高级动作 API 能稳定调用
08

AI / 感官与 Keats

解决“聊天、语音、视觉怎么最后变成动作”。

  • 本地 Bridge
  • MCP / 工具调用
  • 受限动作接口
  • 视觉 / 语音输入
验收：Keats 能调用有限动作控制蜘蛛

HOW TO LEARN

每一个节点，都只用这一套学法

01 · KNOW

知识点

先弄明白“为什么”。只学当前实验会用到的概念，不追求把整本教材吃掉。

02 · BUILD

小实验

每个概念必须落到一个真实动作、接线或代码结果上。学完却没有东西动起来，算没过。

03 · VERIFY

验收标准

能脱离原答案解释原理、修改参数、处理一个小变化，才算这块地图真正点亮。
